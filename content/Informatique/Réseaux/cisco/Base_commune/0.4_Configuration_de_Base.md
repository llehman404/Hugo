# Configuration de base

```text
Router(config)# hostname [nom]	  → définit un nom pour le routeur

Router(config)# enable secret [mot_de_passe]	 → définit le mot de passe du mode privilégié, stocké sous forme
     de chaîne de caractères chiffrée (hash) — non visible en clair

Router(config)# enable password [mot_de_passe]   → définit un mot de passe pour accéder au mode enable
   ⚠⚠⚠ le mot de passe est stocké EN CLAIR !!! privilégier enable secret

Router(config)# username [NOM_UTILISATEUR] secret [MOT_DE_PASSE]	→ définit un utilisateur et son mot de passe chiffré

Router(config)# banner motd # [message] #	 → définit un message d'avertissement à la connexion
     (les # servent de délimiteurs du message)

Router# copy running-config startup-config  → sauvegarde la configuration (alias : do write ou write)
```
