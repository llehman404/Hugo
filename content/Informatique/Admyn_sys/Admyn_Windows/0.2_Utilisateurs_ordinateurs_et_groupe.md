# 🏛️ Fiche AD DS — OU, Utilisateurs, Groupes (module ActiveDirectory)

---

## 1. Unités d'organisation (OU)

### Créer une OU

```powershell
$localisation = @{
    City       = "Lomme"
    Country    = "FR"
    PostalCode = "59610"
    State      = "Hauts-de-France"
}
$domaine = "DC=GreenTechSprint,DC=fr"
$OuName = "Utilisateurs"

New-ADOrganizationalUnit -Name $OuName `
    -Path $domaine `
    -Description "Unité organisationnelle regroupant tous les utilisateurs" `
    -City $localisation.City `
    -Country $localisation.Country `
    -PostalCode $localisation.PostalCode `
    -State $localisation.State `
    -ProtectedFromAccidentalDeletion $false
```

> 💡 `-ProtectedFromAccidentalDeletion $false` dès la création = pas besoin de le retirer avant suppression. Sinon Windows protège l'OU par défaut.

### Rechercher / lister les OUs

```powershell
# Toutes les OUs du domaine
Get-ADOrganizationalUnit -Filter * | Format-Table Name, DistinguishedName

# Une OU précise (avec ses attributs)
Get-ADOrganizationalUnit -Identity "OU=Utilisateurs,DC=GreenTechSprint,DC=fr" | Format-List

# Recherche par motif
Get-ADOrganizationalUnit -Filter "Name -like '*User*'" | Select Name, DistinguishedName
```

### Modifier / supprimer une OU

```powershell
# Autoriser la suppression (l'OU est protégée par défaut)
Set-ADOrganizationalUnit -Identity "OU=Utilisateurs,DC=GreenTechSprint,DC=fr" -ProtectedFromAccidentalDeletion $false

# Supprimer (avec tout son contenu grâce à -Recursive)
Remove-ADOrganizationalUnit -Identity "OU=Utilisateurs,DC=GreenTechSprint,DC=fr" -Recursive -Confirm:$false
```

> ⚠️ `-Recursive` supprime **tout ce que l'OU contient** (utilisateurs, groupes, sous-OUs) — sans lui, la suppression échoue si l'OU n'est pas vide.

## 2. Utilisateurs

### Créer un utilisateur

```powershell
$password = ConvertTo-SecureString "qwerty15!" -AsPlainText -Force

New-ADUser -GivenName "Test" `
    -Surname "User" `
    -Name "Test User" `
    -SamAccountName "Test-User" `
    -UserPrincipalName "Test-User@GreenTechSprint.fr" `
    -AccountPassword $password `
    -Enabled $true `
    -Path "OU=Utilisateurs,DC=GreenTechSprint,DC=fr" `
    -ChangePasswordAtLogon $false `
    -Description "Utilisateur test" `
    -Company "GreenTechSprint.fr" `
    -City "Lomme" `
    -Country "FR" `
    -PostalCode "59610"
```

> 💡 `-AccountPassword` exige un `SecureString` (d'où le `ConvertTo-SecureString -AsPlainText -Force`). Sans `-Enabled $true`, le compte est créé **désactivé**.

### Modifier le mot de passe d'un utilisateur

```powershell
Set-ADAccountPassword -Identity "j.nanas" -Reset -NewPassword (ConvertTo-SecureString -AsPlainText "GhYjKb!M05n" -Force)
```

> 💡 `-Reset` = réinitialisation par un admin (l'ancien mot de passe n'est pas demandé).

### Rechercher / lister les utilisateurs

```powershell
# Tous les utilisateurs d'une OU précise
Get-ADUser -Filter * -SearchBase "OU=Utilisateurs,DC=GreenTechSprint,DC=fr"

# Un utilisateur précis (avec tous ses attributs)
Get-ADUser -Identity "j.nanas" -Properties *

# Recherche par nom
Get-ADUser -Filter "Name -like '*dupont*'" | Select SamAccountName, Enabled

# Les utilisateurs désactivés uniquement
Search-ADAccount -AccountDisabled -SearchBase "OU=Utilisateurs,DC=GreenTechSprint,DC=fr"
```

### Modifier / désactiver / supprimer un utilisateur

```powershell
# Modifier un attribut
Set-ADUser -Identity "j.nanas" -Description "Comptable" -City "Lomme" -Company "GreenTechSprint.fr"

# Renommer (SamAccountName, UPN et nom)
Rename-ADObject -Identity "j.nanas" -NewName "j.nanas2"

# Déplacer dans une autre OU
Get-ADUser "j.nanas" | Move-ADObject -TargetPath "OU=Utilisateurs,DC=GreenTechSprint,DC=fr"

# Désactiver / réactiver (sans supprimer)
Disable-ADAccount -Identity "j.nanas"
Enable-ADAccount  -Identity "j.nanas"

# Supprimer un utilisateur
Remove-ADUser -Identity "j.nanas" -Confirm:$false
```

> ⚠️ Supprimer un utilisateur avec `-Confirm:$false` est irréversible — désactiver d'abord (`Disable-ADAccount`) est la bonne pratique pour un départ.

### Récupérer des infos (rappels)

```powershell
# Toutes les OUs du domaine
Get-ADOrganizationalUnit -Filter * | Format-Table Name, DistinguishedName

# Tous les utilisateurs d'une OU précise
Get-ADUser -Filter * -SearchBase "OU=Utilisateurs,DC=GreenTechSprint,DC=fr"

# Un utilisateur précis (avec ses attributs)
Get-ADUser -Identity "j.nanas" -Properties *
```

## 3. Groupes — Création

```powershell
# Groupe local (DLG — porte les droits sur les ressources)
New-ADGroup -Name "DLG_RW_Compta" -GroupCategory Security -GroupScope DomainLocal -Path "OU=DLG_Local,OU=OU_Groups,DC=GreenTechSprint,DC=fr"

# Groupe global (GG — regroupe les utilisateurs)
New-ADGroup -Name "GG_Compta" -GroupCategory Security -GroupScope Global -Path "OU=GG_Global,OU=OU_Groups,DC=GreenTechSprint,DC=fr"
```

> 💡 `-GroupScope` fait la différence : `DomainLocal` = DLG, `Global` = GG. `-Path` place le groupe dans la bonne OU (sans `-Path` → conteneur Users par défaut).

---

## 4. Groupes — Ajouter des membres

```powershell
# Un utilisateur dans un groupe global
Add-ADGroupMember -Identity "GG_Compta" -Members "jean.dupont"

# Plusieurs d'un coup
Add-ADGroupMember -Identity "GG_Compta" -Members "jean.dupont", "marie.martin"

# Ajouter les membres d'un groupe À UN AUTRE groupe (le GG dans le DLG — le L de AGDLP)
Add-ADGroupMember -Identity "DLG_RW_Compta" -Members "GG_Compta"
```

---

## 5. Groupes — Rechercher / lister

```powershell
# Tous les groupes du domaine
Get-ADGroup -Filter * | Select Name, GroupScope, DistinguishedName

# Un groupe précis
Get-ADGroup -Identity "GG_Compta" | Format-List

# Recherche par motif
Get-ADGroup -Filter "Name -like 'GG_*'" | Select Name, GroupScope

# Les membres d'un groupe
Get-ADGroupMember -Identity "GG_Compta" | Select Name, SamAccountName, ObjectClass

# Dans quels groupes est un utilisateur ?
Get-ADPrincipalGroupMembership jean.dupont | Select Name
```

---

## 6. Groupes — Modifier / Retirer / Supprimer

```powershell
# Modifier : description
Set-ADGroup -Identity "GG_Compta" -Description "Utilisateurs du service compta"

# Renommer
Rename-ADGroup -Identity "GG_Compta" -NewName "GG_Comptabilite"

# Déplacer dans une autre OU
Get-ADGroup "GG_Compta" | Move-ADObject -TargetPath "OU=GG_Global,OU=OU_Groups,DC=GreenTechSprint,DC=fr"

# Retirer UN membre
Remove-ADGroupMember -Identity "GG_Compta" -Member "jean.dupont" -Confirm:$false

# Vider un groupe sans le supprimer
Get-ADGroupMember "GG_Compta" | Remove-ADGroupMember -Identity "GG_Compta" -Confirm:$false

# Supprimer un groupe
Remove-ADGroup -Identity "DLG_RW_Compta" -Confirm:$false
```

> ⚠️ Supprimer un groupe qui porte des droits sur des ressources = ACE orphelines (SID brut affiché sur les dossiers). Retirer les membres, vérifier les droits, puis supprimer.

## 7. Intégrer un ordinateur au domaine AD DS

```powershell
# ⚠️ Exécuter le shell EN MODE ADMINISTRATEUR, sur le poste client
Add-Computer -DomainName GreenTechSprint.fr -Credential Administrateur@GreenTechSprint.fr
Restart-Computer
```

> 💡 `-Credential` ouvre une invite d'authentification ; le compte doit avoir le droit de joindre des ordinateurs au domaine (les admins du domaine, par défaut). Redémarrage obligatoire pour finaliser.

## 8. Le flux AGDLP (chaîne d'examen)

```
Utilisateur → GG → DLG → droits sur la ressource
```

```powershell
# 1. Utilisateur → GG
Add-ADGroupMember -Identity "GG_Compta" -Members "jean.dupont"
# 2. GG → DLG
Add-ADGroupMember -Identity "DLG_RW_Compta" -Members "GG_Compta"
# 3. DLG → ressource (partage, dossier NTFS, imprimante...)
```

> 🧠 **AGDLP** : les **U**tilisateurs vont dans les groupes **G**lobaux, qui vont dans les groupes de domaine **L**ocaux (**DLG**), qui portent les **P**ermissions. Jamais de droits directement à un utilisateur.

---

## 9. 🧠 Mémo

1. **OU** : `New/Set/Remove-ADOrganizationalUnit` — `-ProtectedFromAccidentalDeletion $false` avant de supprimer, `-Recursive` pour vider
2. **Utilisateur** : `New-ADUser` avec mot de passe en `SecureString` + `-Enabled $true` (sinon compte désactivé)
3. **Mot de passe** : `Set-ADAccountPassword -Reset` (admin) — pas d'ancien mdp demandé
4. **Recherche** : `Get-ADOrganizationalUnit -Filter *`, `Get-ADUser -SearchBase "OU=..."`, `Get-ADGroup -Filter *`, `Search-ADAccount -AccountDisabled`
5. **Cycle utilisateur** : `Set-ADUser` (modifier), `Disable/Enable-ADAccount` (désactiver), `Remove-ADUser` (supprimer) — désactiver avant de supprimer
6. **Groupes** : `New-ADGroup` (`Global` = GG, `DomainLocal` = DLG) ; `Add-ADGroupMember` pour membres et imbrication GG → DLG
7. **Modification** : `Set/Rename-ADGroup`, `Move-ADObject` ; **suppression** : `Remove-ADGroupMember`, `Remove-ADGroup`
8. **Domaine** : `Add-Computer -DomainName ... -Credential ...` puis `Restart-Computer` — shell en admin
9. **AGDLP** : les droits vont aux **DLG**, jamais aux utilisateurs directement
