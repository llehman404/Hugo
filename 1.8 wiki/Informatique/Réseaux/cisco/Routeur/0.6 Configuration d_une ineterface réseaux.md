# Configuration des interfaces réseau d'un routeur

```text
Router(config)# interface GigabitEthernet0/0
   → entre dans le mode de configuration de cette interface
     (raccourci possible : int g0/0)

Router(config-if)# ip address 192.168.1.1 255.255.255.0
   → configure l'adresse IP et le masque de l'interface

Router(config-if)# no shutdown
   → active l'interface (par défaut elle est administrativement
     fermée : état "shutdown"). Sans cette commande, le port
     reste down et rien ne passe.

Router(config-if)# exit
   → sort du mode de configuration d'interface

Router(config)# exit
   → sort du mode de configuration globale

Router# copy running-config startup-config
   → sauvegarde la configuration (alias : do write ou write)
```
