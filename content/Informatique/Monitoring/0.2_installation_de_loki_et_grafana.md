# Install Loki and Grafana 

## Connect to Grafana apt sources

```bash
sudo apt-get install -y apt-transport-https wget gnupg

sudo mkdir -p /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/grafana.asc https://apt.grafana.com/gpg-full.key
sudo chmod 644 /etc/apt/keyrings/grafana.asc

echo "deb [signed-by=/etc/apt/keyrings/grafana.asc] https://apt.grafana.com stable main" | sudo tee -a /etc/apt/sources.list.d/grafana.list

# Updates the list of available packages
sudo apt-get update

# Installs the latest OSS release:
sudo apt-get install grafana
```
## Install Grafana

```bah
sudo apt install grafana
```

## Install and config Loki

### Create user and directory

> 📝 **Note** : vérifier d'abord si l'utilisateur existe déjà — selon les  
> versions, le paquet `loki` peut le créer tout seul à l'installation  
> (`grep loki /etc/passwd`). Si c'est le cas, sauter les commandes `addgroup`  
> / `adduser`.

```bash
sudo apt install loki

sudo mkdir /var/lib/loki
sudo mkdir /var/lib/loki/chunks /var/lib/loki/rules

# Création de l'utilisateur loki seulement s'il n'existe pas déjà :
sudo addgroup loki
sudo adduser loki --system --home /var/lib/loki --shell /sbin/false --group loki

sudo chown -R loki:loki /var/lib/loki
```

### Config Loki

```bash
sudo micro /etc/loki/config.yml
```

```yaml
auth_enabled: false

server:
  http_listen_port: 3100
  grpc_listen_port: 9096
  # info en prod ; repasser à debug uniquement pour dépanner l'installation
  log_level: info
  grpc_server_max_concurrent_streams: 1000

common:
  instance_addr: 127.0.0.1
  path_prefix: /var/lib/loki
  storage:
    filesystem:
      chunks_directory: /var/lib/loki/chunks
      rules_directory: /var/lib/loki/rules
  replication_factor: 1
  ring:
    kvstore:
      store: inmemory

query_range:
  results_cache:
    cache:
      embedded_cache:
        enabled: true
        max_size_mb: 100

# Rétention : sans ça, Loki garde les données indéfiniment et finit par
# remplir le disque (équivalent de logrotate pour rsyslog). Durée à ajuster.
compactor:
  retention_enabled: true

limits_config:
  retention_period: 30d
  metric_aggregation_enabled: true
  enable_multi_variant_queries: true

schema_config:
  configs:
    - from: 2020-10-24
      store: tsdb
      object_store: filesystem
      schema: v13
      index:
        prefix: index_
        period: 24h

pattern_ingester:
  enabled: true
  metric_aggregation:
    loki_address: localhost:3100

# Ruler : utile seulement si un Alertmanager est installé (port 9093).
# À décommenter si on ajoute Alertmanager à l'architecture plus tard.
#ruler:
#  alertmanager_url: http://localhost:9093

frontend:
  encoding: protobuf

# By default, Loki will send anonymous, but uniquely-identifiable usage and configuration
# analytics to Grafana Labs. These statistics are sent to https://stats.grafana.org/
#
# Statistics help us better understand how Loki is used, and they show us performance
# levels for most users. This helps us prioritize features and documentation.
# For more information on what's sent, look at
# https://github.com/grafana/loki/blob/main/pkg/analytics/stats.go
# Refer to the buildReport method to see what goes into a report.
#
# If you would like to disable reporting, uncomment the following lines:
#analytics:
#  reporting_enabled: false
```

## Démarrage / vérification

```bash
sudo systemctl enable --now loki
sudo systemctl enable --now grafana-server

sudo systemctl status loki

# Loki répond "ready" quand il est opérationnel :
curl http://localhost:3100/ready
```

## Connexion Grafana ↔ Loki

L'interface Grafana est intuitive, donc en bref :

1. Ouvrir Grafana : `http://<serveur>:3000` (identifiants par défaut : `admin` / `admin`)
2. *Connections → Data sources → Add data source → Loki*
3. URL : `http://localhost:3100` (ou `http://<ip-serveur>:3100` si Grafana  
 est sur une autre machine) → *Save &amp; Test*
4. Menu *Explore* pour requêter, ex. : `{job="rsyslog"}`
