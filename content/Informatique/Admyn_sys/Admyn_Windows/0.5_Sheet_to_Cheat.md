## Gestion des utilisateurs locaux

```powershell
Get-LocalUser 
Rename-LocalUser -Name "Test_User" -NewName "loupulus"
```

## Change un mot de passe local

``` powershell
Get-LocalUser # identifier l'utilisateur dont on veux changer le nom 

#Compléter et lancer ce spript
$NewPwd = Read-Host -AsSecureString # Créer une variable secure-string
$NewPwdText = "Mon_MDP" #Créer une variable contenat le motde passe 
$NewPwd = $NewPwdText | ConvertTo-SecureString -AsPlainText -Force # assignée est convertit le mot de passe en secure string.
Get-LocalUser -Name "admin" | Set-LocalUser -Password $NewPwd # récuperer le nom du User et le passer a la commande effectuant le changement de nom 
# ou 
Get-LocalUser -Name "admin" | Set-LocalUser -Password $NewPwd -UserMayChangePassword $true -PasswordNeverExpires $true
```

## Gestion Firewall

```powershell
- Set-NetFirewallProfile -All -Enabled False
- Set-NetFirewallProfile -All -Enabled True
- Get-NetFirewallProfile | Format-Table Name, Enabled
- Set-NetFirewallProfile -Profile Public -Enabled False
- Set-NetFirewallProfile -Profile Public -Enabled True
```

## Désactiver OU activer le dhc

```powershell
Set-NetIPInterface -InterfaceIndex 12 -Dhcp {Enabled/Disabled}
```

## Supprimer une ancienne adresse fixe 

```powershell
Remove-NetIPAddress –InterfaceIndex 12 –IPAddress 10.10.10.10 –PrefixLength 16 –DefaultGateway 10.10.10.25
```

## Activer attribution adesse par DHCP
```powershell
Get-NetAdapter

#ou alors 
Set-NetIPInterface -InterfaceIndex 7 -AddressFamily IPv4 -Dhcp Enabled

Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 1.1.1.1

ipconfig /renew
```
