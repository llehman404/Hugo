# Navigation dans l'IOS Cisco

## Les modes de l'IOS

```text
Router>               Mode utilisateur : accessible à l'arrivée dans le CLI,
                      permet d'exécuter des commandes de base (diagnostic)

Router#               Mode privilégié : accès aux commandes avancées
                      (show, debug)

Router(config)#       Mode de configuration globale : modifier la
                      configuration du routeur

Router(config-if)#    Mode de configuration d'interface : modifier une
                      interface spécifique

Router(config-line)#  Mode de configuration de ligne : modifier un accès
                      distant (SSH)
```

## Exemple de navigation entre les différents modes

```text
Router> enable  → passe dans le mode donnant accès aux commandes avancées

Router# configure terminal  → passe dans le mode de configuration du routeur

Router(config)# interface [nom de l'interface (ex: GigabitEthernet0/0)]	 → passe dans le mode permettant de configurer une interface spécifique

Router(config-if)# exit → retourne au mode précédent

Router(config)# exit → retourne au mode précédent

Router# disable → retourne au mode précédent

Router>
```
