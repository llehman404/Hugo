# Premiére création d'une 

Dans ce Tp nous allons créer une premiere vm sous linux. Cette vm sera un Debian server sans interface graphique.
le protocole pour ce connecter graphiquement a la console sera vnc.

```bash
$ virsh -c qemu:///system version
Using library: libvirt 10.0.0
Running hypervisor: QEMU 8.2.2
$ virsh net-list
 Name      State    Autostart   Persistent
--------------------------------------------
 default   active   yes         yes
sudo virt-install \
  --name test-vm \
  --memory 2048 \
  --vcpus 2 \
  --disk size=20 \
  --network network=default \
  --graphics vnc \
  --os-type linux \
  --os-variant debian12 \
  --cdrom /home/loupulus/ISO/debian-12.13.0-amd64-netinst.iso
Starting install...
$ virsh list
 Id   Name      State
-------------------------
 1    test-vm   running
$ virsh domifaddr test-vm
 Name       MAC address          Protocol     Address
-------------------------------------------------------
 vnet0      52:54:00:ab:cd:ef    ipv4         192.168.122.45/24
```
