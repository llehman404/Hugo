# 🔐 Les deux types de droits — Introduction

Un dossier partagé est protégé par **deux barrières successives** :

- **NTFS** — les droits du **dossier/fichier** lui-même (`icacls`). S'appliquent **toujours** : accès local ET réseau.
- **SMB** — les droits du **partage** (`*-SmbShareAccess`). Ne s'appliquent **qu'aux accès réseau**, via `\\serveur\partage`.

```
Accès local  (F:\Dossier)      → [NTFS]                    → accès
Accès réseau (\\SRV\Partage)   → [SMB] puis [NTFS]         → accès
```

**Droit effectif = le PLUS RESTRICTIF des deux.** Une barrière ne peut jamais élargir ce que l'autre refuse :

| Droit SMB | Droit NTFS | Résultat réel |
|---|---|---|
| Full | Lecture | Lecture seule |
| Lecture | Full | Lecture seule |
| Change | Modify | Lecture + écriture ✅ |
| Refusé | Full | Aucun accès |

> 💡 **Best practice Microsoft** : SMB généreux (Full/Change à Everyone) + NTFS strict (filtrage fin par groupes DLG). L'inverse marche aussi (NTFS large, SMB filtrant), mais le filtrage fin côté SMB seul est impossible.
