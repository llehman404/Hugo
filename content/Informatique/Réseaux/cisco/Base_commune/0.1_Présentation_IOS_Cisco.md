# IOS Cisco
&nbsp;

## Présentation

L’IOS Cisco (Internetwork Operating System) est le système d’exploitation intégré aux équipements réseau Cisco, tels que les routeurs et commutateurs. Il permet de gérer et configurer les appareils via une interface en ligne de commande (CLI).

Contrairement aux systèmes d’exploitation classiques (Windows, macOS, Linux), l’IOS Cisco est entièrement basé sur des commandes textuelles.

C’est un système multitâche qui assure :

- Le routage des paquets entre réseaux
- La gestion des interfaces et des adresses IP
- Le contrôle des accès et la sécurité
- L’exécution des protocoles réseau (OSPF, EIGRP, VLANs, etc.)

&nbsp;

## Les différent modes 

| Mode | CLI | Description |
| --- | --- | --- |
| Mode utilisateur | Router> | Permet d’exécuter des commandes de surveillance (ex: show, ping) (diagnostic). |
| Mode privilégié | Router# | Permet d’accéder aux commandes de configuration (ex: configure, debug, reload). |
| Mode de configuration globale | Router(config)# | Permet de modifier la configuration du routeur. |
| Mode de configuration d’interface | Router(config-if)# | Permet de configurer une interface spécifique. |
| Mode de configuration de ligne | Router(config-line)# | Permet de configurer un accès distant (Telnet/SSH). |
