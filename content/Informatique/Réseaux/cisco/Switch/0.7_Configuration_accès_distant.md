# Configuration de l'accès distant

## Configuration de la console (line console 0)

**Utilisation** : connexion physique directe au routeur via câble console.

```text
Router(config)# line console 0
   → entre dans le mode de configuration de la ligne console

Router(config-line)# password admin123
   → définit le mot de passe de la console

Router(config-line)# login
   → oblige à saisir le mot de passe à la connexion console

Router(config-line)# exit
   → sort du mode de configuration de ligne
```

## Configuration des lignes VTY (line vty 0 4)

**Utilisation** : les lignes VTY (Virtual Teletype) permettent les
connexions distantes via Telnet ou SSH.

```text
Router(config)# hostname SecureRouter
   → définit le nom de l'appareil

Router(config)# ip domain-name example.com
   → définit le nom de domaine de l'appareil
     (requis pour générer les clés RSA)

Router(config)# crypto key generate rsa
   → crée la clé cryptographique RSA
     (choisir au moins 1024 bits)

Router(config)# username [NOM_UTILISATEUR] secret [MOT_DE_PASSE]
   → définit un utilisateur et son mot de passe chiffré
     (sera utilisé par "login local")

Router(config)# line vty 0 4
   → entre dans la configuration des lignes VTY 0 à 4
     (5 connexions distantes simultanées possibles)

Router(config-line)# transport input ssh
   → autorise UNIQUEMENT SSH, pas Telnet (non chiffré)

Router(config-line)# login local
   → impose l'authentification par compte utilisateur local
     (celui créé avec "username ... secret ...")

Router(config-line)# end
   → retourne directement au mode privilégié
     (plus rapide que plusieurs "exit")

Router# copy running-config startup-config
   → sauvegarde la configuration
```
