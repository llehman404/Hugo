## Serveur
⚠⚠⚠ Attention avec policy drop. Si  on fait cette configuration sur un serveur distant avec une connexion ssh il y a un grand risque de ce faire drop. preferer la solution 1 dans ce cas. 
### Solution 1
- [x] `sudo apt install nftables`
- [x] `sudo nano /etc/nftables.conf`
```
table inet Baal_Firewall {
    chain input {
        type filter hook input priority 0; policy drop;

        # Autorise le trafic loopback
        iif "lo" accept

        # Autorise les connexions établies/associées
        ct state established,related accept

        # Autorise SSH (port 22)
        tcp dport 1090 accept

        # Autorise ICMP (ping)
        icmp type echo-request accept

        # Log les connexions refusées (optionnel)
        counter drop
    }

    chain output {
        type filter hook output priority 0; policy accept
    }

    chain forward {
        type filter hook forward priority 0; policy drop
    }
}

````
- [x]  `sudo nft -f /etc/nftables.conf`  -> charg les régles
- [x]  `sudo nft list ruleset` -> vérifie les régles 
- [x] `sudo systemctl enable --now nftables.service`
- [x] `sudo systemctl start nftables.service`
`sudo nft flush ruleset` -> si besoins supprime les régles existante

### Solution 2 

- [ ] `sudo nft add table inet Baal_Firewall`
- [ ] `sudo nft add chain inet Baal_Firewall input { type filter hook input priority 0 \; policy drop \; }`
- [ ] `sudo nft add chain inet Baal_Firewall output { type filter hook output priority 0 \; policy accept \; }`

- [ ] `sudo nft add rule inet Baal_Firewall input iifname "lo" accept`
- [ ] `sudo nft add rule inet Baal_Firewall input ct state established,related accept`
- [ ] `sudo nft add rule inet Baal_Firewall input tcp dport 22 accept`
- [ ] `sudo nft add rule inet Baal_Firewall input icmp type echo-request accept`
- [ ] `sudo nft add rule inet Baal_Firewall input counter drop`
- [ ] `sudo nft list ruleset`
- [ ] `sudo nft list ruleset | sudo tee /etc/nftables.conf`
- [ ] `sudo systemctl enable nftables.service`
- [ ] `suod systemctl start nftables.service`
