# 🗑️ Cheat Sheet — Supprimer sur Cisco IOS

> **Règle d'or : `no` + la commande d'origine.**

## Sous-interfaces
```bash
no interface GigabitEthernet0/0.10      ! supprimer la sous-interface
no encapsulation dot1Q 20               ! retirer juste l'encapsulation
no ip address                           ! retirer l'IP
default interface GigabitEthernet0/0.10 ! remettre à zéro (sans supprimer)
```

## Interfaces
```bash
no ip address
no description
shutdown
default interface GigabitEthernet0/0
```

## VLANs (switch)
```bash
no vlan 30                              ! supprimer un VLAN
no switchport access vlan               ! détacher un port du VLAN
no switchport mode trunk
no switchport trunk allowed vlan 30
no switchport trunk native vlan
```

## Routage & DHCP
```bash
no ip route 10.0.20.0 255.255.255.0 10.0.10.2
no router rip                           ! (aussi : no router ospf 1 / eigrp 100)
no ip dhcp pool MON-POOL                ! supprimer un pool
no ip dhcp excluded-address 10.0.10.1 10.0.10.10
```

## ACLs
```bash
no access-list 100                      ! supprimer une ACL entière
no ip access-list standard MON-ACL      ! supprimer une ACL nommée
no access-group 10 in                   ! la détacher d'une interface
! supprimer UNE ligne d'une ACL nommée :
ip access-list standard MON-ACL
 no 10
```

## Reset total (TPs)
```bash
erase startup-config
delete vlan.dat                        ! switch : sinon VLANs survivent !
reload
```

## Vérifier
```bash
show running-config
show ip interface brief
show vlan brief
```
