# 📄 Fiche Droits NTFS — `icacls`

---

## 1. Lister les droits

```powershell
icacls "F:\Partage_Compta"

# Variante PowerShell objet
(Get-Acl "F:\Partage_Compta").Access |
    Select-Object IdentityReference, FileSystemRights, IsInherited
```

Décoder une ligne :

```
BUILTIN\Utilisateurs:(I)(OI)(CI)(RX)
                     │  │   │   └─ les droits (RX...)
                     │  │   └─ drapeaux de propagation
                     │  └─ drapeaux de propagation
                     └─ (I) = hérité du dossier parent
```

> 💡 Le GUI regroupe par compte ("Spéciale" = plusieurs droits) ; icacls affiche **un droit par ligne**. Une "Spéciale" GUI = souvent 2 lignes CMD — personne en plus !

---

## 2. Les droits simples

| Acronyme | Nom | L'utilisateur peut |
|---|---|---|
| **F** | Contrôle total | Tout + **modifier les permissions** + prendre possession |
| **M** | Modification | Lire, écrire, créer, renommer, **supprimer** |
| **RX** | Lecture et exécution | Parcourir, lire, lancer les .exe |
| **R** | Lecture | Lire uniquement, aucune écriture |
| **W** | Écriture | Créer/écrire sans pouvoir relire (rare, jamais seul) |
| **D** | Suppression | Supprimer uniquement |

Droits élémentaires : `DE` (supprimer), `RC` (lire permissions), `WDAC` (modifier permissions), `WO` (prendre possession), `WD`/`AD` (écrire/ajouter des données).

## 3. Drapeaux de propagation — AVEC EXEMPLES

Le but des drapeaux : décider **à quoi s'applique le droit** dans le dossier et en dessous.

| Flag | Nom | S'applique à... |
|---|---|---|
| *(aucun)* | — | **Le dossier lui-même seulement** |
| `(OI)` | Object Inherit | Les **fichiers** |
| `(CI)` | Container Inherit | Les **sous-dossiers** |
| `(OI)(CI)` | — | Dossier + fichiers + sous-dossiers (tout l'arbre) |
| `(IO)` | Inherit Only | **Enlève le droit au dossier lui-même** — ne garde que ce que désignent OI/CI |
| `(NP)` | No Propagate | Le droit **s'arrête au 1er niveau** de sous-dossiers |
| `(I)` | Inherited | Marqueur : droit **hérité** du parent (non supprimable directement) |

### Exemples concrets

```powershell
# 1. Dossier + tout ce qu'il contient (LE cas standard d'un partage)
icacls "F:\Compta" /grant "GG_Compta:(OI)(CI)M"
# → peut modifier F:\Compta, F:\Compta\factures.xlsx, F:\Compta\2024\budget.xlsx

# 2. Le dossier lui-même SEULEMENT (rien en dessous)
icacls "F:\Compta" /grant "GG_Compta:M"
# → peut modifier le dossier, mais PAS les fichiers dedans !

# 3. Contenu seulement, PAS le dossier (c'est le (IO))
icacls "F:\Compta" /grant "GG_Compta:(OI)(CI)(IO)M"
# → peut créer/modifier factures.xlsx et 2024\, mais pas toucher au dossier F:\Compta
#   (c'est la ligne CRÉATEUR PROPRIÉTAIRE vue dans le GUI)

# 4. Première génération de sous-dossiers seulement (c'est le (NP))
icacls "F:\Compta" /grant "GG_Compta:(CI)(NP)M"
# → peut modifier F:\Compta\2024\ mais PAS F:\Compta\2024\janvier\
#   (le droit ne descend pas plus loin que le 1er niveau)
```

> ⚠️ `(IO)` **tout seul ne veut rien dire** — il se combine : `(OI)(CI)(IO)` = "aux fichiers et sous-dossiers, mais pas au dossier". Le GUI l'affiche "S'applique à : Les sous-dossiers et les fichiers seulement".

## 4. Donner / retirer des droits

```powershell
# Donner (pattern TP : aux groupes DLG, avec propagation)
icacls "F:\Compta" /grant "LOUPULUS\DLG_RW_Compta:(OI)(CI)M"
icacls "F:\Compta" /grant "LOUPULUS\GG_Larbins:(OI)(CI)RX"

# Refus explicite (prime sur TOUT)
icacls "F:\Compta" /deny "LOUPULUS\Stagiaire:(OI)(CI)F"

# Retirer toutes les ACE d'un compte
icacls "F:\Compta" /remove "BUILTIN\Utilisateurs"

# Retirer seulement les accords / seulement les refus
icacls "F:\Compta" /remove:g "BUILTIN\Utilisateurs"
icacls "F:\Compta" /remove:d "LOUPULUS\Stagiaire"
```

> 🚨 Une ACE marquée `(I)` est **indestructible par `/remove`** (le parent la recolle). Figer d'abord l'héritage (§ 5).
> Un drapeau de droits (`F` → `M`...) **ne s'édite pas** : `/remove` puis `/grant`.

---

## 5. L'héritage

```powershell
icacls "F:\Compta" /inheritance:d   # Couper + COPIER les droits hérités (deviennent modifiables)
icacls "F:\Compta" /inheritance:r   # Couper + SUPPRIMER tous les droits hérités
icacls "F:\Compta" /inheritance:e   # Réactiver l'héritage du parent
```

> ⚠️ Toujours garder `AUTORITE NT\Système` et `BUILTIN\Administrateurs` en Full — sinon dossier inadministrable.

---

## 6. Sauvegarder / restaurer les ACL

```powershell
icacls "F:\Compta" /save "C:\acl.txt" /t   # sauvegarder
icacls "F:\" /restore "C:\acl.txt"        # restaurer (depuis le parent !)
```

## 7. Piège : "nom de compte introuvable" (erreur 1332)

Sur un serveur français, les noms anglais peuvent échouer → utiliser le **SID bien connu** avec l'étoile :

```powershell
icacls "F:\Compta" /grant "*S-1-5-11:(OI)(CI)M"   # *S-1-5-11 = Utilisateurs authentifiés
```

| Compte | SID |
|---|---|
| Tout le monde | `S-1-1-0` |
| Utilisateurs authentifiés | `S-1-5-11` |
| Créateur propriétaire | `S-1-3-0` |
| Système | `S-1-5-18` |

Ou le nom français : `"AUTORITE NT\Utilisateurs authentifiés"`, `"CREATEUR PROPRIETAIRE"`.

---

## 8. 🧠 Mémo

1. Droit effectif = le plus restrictif NTFS/SMB ; un refus explicite (`/deny`) prime sur tout
2. `(OI)(CI)` = tout l'arbre ; rien = dossier seul ; `(OI)(CI)(IO)` = contenu sans le dossier ; `(NP)` = stop au 1er niveau
3. `(I)` = hérité → `/inheritance:d` ou `:r` avant tout `/remove`
4. Pas d'édition de drapeaux : `/remove` + `/grant`
5. Les droits vont aux **DLG** (AGDLP), jamais aux utilisateurs directement
