# 📄 Fiche Droits SMB — Partage

---

## 1. Les 3 niveaux (et c'est tout)

| `-AccessRight` | GUI | L'utilisateur peut |
|---|---|---|
| `Read` | Lecture | Parcourir et lire |
| `Change` | Modification | Lire **+ écrire** (créer, modifier, supprimer) |
| `Full` | Contrôle total | Change + gérer les permissions du partage |

> **"Lecture + écriture" = `Change`.** Il n'y a pas de niveau "écriture seule".
> ⚠️ **Pas d'héritage en SMB** : les droits de partage sont **plats** — une liste par partage, point. L'héritage, c'est NTFS uniquement.

---

## 2. Créer / modifier / supprimer un partage

```powershell
# Créer (sans droits spécifiés → Everyone en Lecture par défaut)
New-SmbShare -Name "Partage_Compta" -Path "F:\Partage_Compta" -Description "Données compta"

# Créer avec droits directs
New-SmbShare -Name "Partage_Compta" -Path "F:\Partage_Compta" -FullAccess "LOUPULUS\GG_Compta"

# Méthode officielle en 2 commandes
New-SmbShare -Name "Partage_Compta" -Path "F:\Partage_Compta" |
    Grant-SmbShareAccess -AccountName "Tout le monde" -AccessRight Full -Force

# Modifier / supprimer
Set-SmbShare -Name "Partage_Compta" -Description "..." -ConcurrentUserLimit 50
Remove-SmbShare -Name "Partage_Compta" -Force
```

---

## 3. Les 5 cmdlets de droits

```powershell
Get-SmbShareAccess -Name "Partage_Compta"                                    # LISTER
Grant-SmbShareAccess   -Name "X" -AccountName "LOUPULUS\DLG_RW_Compta" -AccessRight Change -Force
Revoke-SmbShareAccess  -Name "X" -AccountName "Tout le monde" -Force          # retirer un droit accordé
Block-SmbShareAccess   -Name "X" -AccountName "LOUPULUS\Stagiaire" -Force     # refus explicite
Unblock-SmbShareAccess -Name "X" -AccountName "LOUPULUS\Stagiaire" -Force     # lever un refus
```

- `Revoke` = enlever un droit **accordé**
- `Block` = **refus explicite** (prime sur tous les accords)
- `Unblock` = retirer ce refus

### Pattern TP : lecture pour tous, écriture pour un groupe

```powershell
Revoke-SmbShareAccess -Name "X" -AccountName "Tout le monde" -Force
Grant-SmbShareAccess  -Name "X" -AccountName "LOUPULUS\GG_Compta"         -AccessRight Change -Force
Grant-SmbShareAccess  -Name "X" -AccountName "LOUPULUS\GG_Larbins"       -AccessRight Read   -Force
Grant-SmbShareAccess  -Name "X" -AccountName "LOUPULUS\Admins du domaine" -AccessRight Full  -Force
```

## 4. Utilisateurs et sessions

```powershell
# Qui est connecté
Get-SmbSession | Select ClientComputerName, User, NumOpenFiles, StartTime

# Quels fichiers ouverts (verrous) et par qui
Get-SmbOpenFile
Get-SmbOpenFile | Where-Object { $_.Session -match "jean.dupont" }   # un utilisateur précis

# Expulser
Close-SmbSession -SessionId 844444444444       # déconnecter tout un utilisateur
Close-SmbOpenFile -FileId 444444444444         # fermer UN fichier verrouillé
```

> ⚠️ `Close-*` coupe **brutalement** — données non enregistrées perdues. Réserver aux verrous bloquants.

## 5. Dépannage — traduction des comptes

| Erreur | Signification |
|---|---|
| **1337** "Structure d'ID de sécurité non valide" | Nom **invalide** (ex: `*` en joker) |
| **1332** "Le mappage... n'a pas été effectué" | Nom valide mais **traduction impossible** (OS français, souci DC) |

### Solution : les SID bien connus

```powershell
New-SmbShare -Name "X" -Path "F:\X" -FullAccess "S-1-1-0"   # S-1-1-0 = Tout le monde
Grant-SmbShareAccess -Name "X" -AccountName "S-1-5-11" -AccessRight Change -Force
```

| Compte | SID |
|---|---|
| Tout le monde | `S-1-1-0` |
| Utilisateurs authentifiés | `S-1-5-11` |
| Créateur propriétaire | `S-1-3-0` |
| Administrateurs | `S-1-5-32-544` |

Noms français acceptés sur serveur FR : `"Tout le monde"`, `"AUTORITE NT\Utilisateurs authentifiés"`.

### Dernier recours

```powershell
net share Partage_Compta=F:\Partage_Compta /GRANT:"Tout le monde,FULL"
```

## 6. Vérification (les deux barrières)

```powershell
Get-SmbShare -Name "Partage_Compta" | Format-List
Get-SmbShareAccess -Name "Partage_Compta"     # droits SMB
icacls "F:\Partage_Compta"                    # droits NTFS (voir fiche NTFS)
```

---

## 7. 🧠 Mémo

1. 3 niveaux seulement : `Read` / `Change` / `Full`
2. Droit effectif = **le plus restrictif** SMB vs NTFS ; `Block-SmbShareAccess` prime sur tout
3. Pas d'héritage en SMB — filtrage fin = NTFS (ou partages séparés sur le même dossier)
4. Erreur 1332 → **SID bien connu** (`S-1-1-0`, `S-1-5-11`)
5. `Get-SmbSession` / `Get-SmbOpenFile` = qui, quoi ; `Close-*` = expulser
