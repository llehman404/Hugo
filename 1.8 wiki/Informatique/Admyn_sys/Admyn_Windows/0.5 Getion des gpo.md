# ⚙️ Fiche Stratégies de groupe (GPO) — module GroupPolicy

---

## 1. Les 3 concepts à démêler (la clé de tout)

```
1. LA GPO (l'objet)   → le "règlage"        → New-GPO
2. LE LIEN (le link)  → OÙ elle s'applique  → New-GPLink (sur une OU / domaine / site)
3. LE FILTRAGE        → à QUI précisément   → Set-GPPermissions
```

Et dans la GPO, deux "moitiés" selon la cible :


| Moitié de la GPO              | Appliquée à...              | S'applique quand ?                             |
| ----------------------------- | --------------------------- | ---------------------------------------------- |
| Configuration **Utilisateur** | la session de l'utilisateur | à l'**ouverture de session**                   |
| Configuration **Ordinateur**  | la machine elle-même        | au **démarrage** + refresh toutes les \~90 min |


> 💡 D'où la séparation classique des OUs : une OU `Utilisateurs` (GPO user), une OU `Ordinateurs` (GPO machine).

---

## 2. Voir / lister

```powershell
# Toutes les GPOs du domaine
Get-GPO -All

# Une GPO précise
Get-GPO -Name "GPO_Fond_Ecran" | Format-List

# Quelles GPOs une OU reçoit (héritage compris)
Get-GPInheritance -Target "OU=Utilisateurs,DC=GreenTechSprint,DC=fr"

# Les liens d'une OU
Get-GPLink -Target "OU=Utilisateurs,DC=GreenTechSprint,DC=fr"
```

---

## 3. Créer et lier

```powershell
# Créer une GPO et la lier à une OU en une ligne (pipeline)
New-GPO -Name "GPO_Fond_Ecran" | New-GPLink -Target "OU=Utilisateurs,DC=GreenTechSprint,DC=fr"

# Ou en deux temps
New-GPO -Name "GPO_Fond_Ecran" -Comment "Fond d'écran entreprise"
New-GPLink -Name "GPO_Fond_Ecran" -Target "OU=Utilisateurs,DC=GreenTechSprint,DC=fr"
```

## 4. Régler (les valeurs)

```powershell
# Le registre = la base des réglages GPO (ici : fond d'écran)
Set-GPRegistryValue -Name "GPO_Fond_Ecran" `
    -Key "HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\System" `
    -ValueName "Wallpaper" -Type String -Value "F:\wallpaper.jpg"

# Retirer un réglage précis
Remove-GPRegistryValue -Name "GPO_Fond_Ecran" `
    -Key "HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\System" -ValueName "Wallpaper"
```

> 💡 `HKCU\...` = réglage **Utilisateur** · `HKLM\...` = réglage **Ordinateur**.

### La limite de `Set-GPRegistryValue` (la vraie difficulté)

`Set-GPRegistryValue` ne sait écrire que **des valeurs de registre** — c'est déjà beaucoup (fonds d'écran, pare-feu, restrictions...), mais il **ne sait pas créer** :

- des **raccourcis** sur le bureau,
- des **mappages de lecteurs réseau** (lecteur Z: → \\SRV\\Partage),
- des **installations de logiciels**,
- des **scripts** de démarrage/ouverture de session,
- des réglages qui ne passent pas par le registre (pare-feu avancé, modèles d'administration complexes...).

### Le réflexe pro : GPMC une fois, PowerShell pour tout le reste

Pour ces réglages complexes, on **édite la GPO une seule fois dans la console graphique GPMC** (`gpmc.msc`), puis on l'utilise comme un **modèle** que PowerShell clone et déploie :

```powershell
# La GPO "modèle" (réglée à la main dans GPMC) est clonée autant de fois que nécessaire
Copy-GPO -SourceName "GPO_Modele" -TargetName "GPO_Compta"

# Et pour un autre domaine : backup → import
Backup-GPO -Name "GPO_Modele" -Path "C:\BackupGPO"
Import-GPO -TargetName "GPO_Compta" -Path "C:\BackupGPO" -BackupId "<guid-du-backup>"
```

> 💡 En clair : **GPMC = l'outil de création du contenu**, **PowerShell = l'outil d'automatisation** (créer les liens, cloner, filtrer, déployer, diagnostiquer). Personne ne règle des mappages de lecteurs en ligne de commande — et c'est normal.

## 5. Ordre des liens et héritage

```powershell
# Réordonner / activer / désactiver un lien
Set-GPLink -Name "GPO_Fond_Ecran" -Target "OU=Utilisateurs,DC=GreenTechSprint,DC=fr" -Order 1 -LinkEnabled Yes

# Forcer une GPO (prime sur tout ce qui est en dessous)
Set-GPLink -Name "GPO_Fond_Ecran" -Target "OU=Utilisateurs,DC=GreenTechSprint,DC=fr" -Enforced Yes

# Bloquer l'héritage sur une OU (elle ignore ce qui vient d'au-dessus)
Set-GPInheritance -Target "OU=Utilisateurs,DC=GreenTechSprint,DC=fr" -IsProtected $true

# Réactiver l'héritage
Set-GPInheritance -Target "OU=Utilisateurs,DC=GreenTechSprint,DC=fr" -IsProtected $false
```

### L'ordre de priorité

```
Site → Domaine → OU → Sous-OU → ...     (le PLUS PROCHE / le DERNIER gagne)
```

### 1. Ordre des liens sur une MÊME OU (LinkOrder)

Quand **plusieurs GPOs sont liées à la même OU**, elles s'appliquent **dans l'ordre inverse de la liste** : le lien d'`Order 1` est traité en **dernier**, donc c'est lui qui **écrase les autres** en cas de conflit.

> **Exemple** : l'OU `Utilisateurs` a 2 GPOs liées — `GPO_Fond_Ecran` (Order 1) et `GPO_Security` (Order 2).  
> Les deux s'appliquent (elles se **complètent**), mais si les deux règlent **la même valeur** (ex: le même fond d'écran), c'est **celle d'Order 1** qui gagne.

```powershell
# Mettre une GPO en position dominante sur une OU
Set-GPLink -Name "GPO_Fond_Ecran" -Target "OU=Utilisateurs,DC=..." -Order 1
```

### 2. Enforced (forcée)

Marque **une GPO précise** pour que **personne en dessous ne puisse la contredire**. Même si une sous-OU définit le réglage contraire, ou même si elle bloque l'héritage, la GPO enforced passe quand même.

> **Exemple** : `GPO_Securite_Minimale` (mot de passe 12 caractères) liée au **domaine** et marquée Enforced → toutes les OUs, même celles qui tentent de mettre 8 caractères, recevront 12.

```powershell
Set-GPLink -Name "GPO_Securite_Minimale" -Target "DC=GreenTechSprint,DC=fr" -Enforced Yes
```

### 3. Block inheritance (bloquer l'héritage)

Se règle **sur une OU** (pas sur une GPO) : elle refuse **tout** ce qui vient d'au-dessus (domaine, OU parente) et ne garde que les GPOs qui lui sont **directement liées**.

> **Exemple** : l'OU `Direction` bloque l'héritage → elle ne reçoit plus les GPOs du domaine, seulement les siennes.  
> ⚠️ Exception : une GPO **Enforced** au-dessus traverse quand même le blocage (Enforced &gt; Block).

```powershell
Set-GPInheritance -Target "OU=Direction,DC=GreenTechSprint,DC=fr" -IsProtected $true   # bloquer
Set-GPInheritance -Target "OU=Direction,DC=GreenTechSprint,DC=fr" -IsProtected $false  # rétablir
```

### 4. Le refus explicite (GpoDeny)

Le **seul qui gagne contre tout**, Enforced compris. On le pose sur une GPO pour un groupe précis : ce groupe ne recevra jamais cette GPO, quoi qu'il arrive.

> **Exemple** : `GPO_Verrouillage_USB` s'applique à toute l'OU, mais les développeurs ont besoin de leurs clés USB → `GpoDeny` sur le groupe `GG_Dev`.

```powershell
Set-GPPermissions -Name "GPO_Verrouillage_USB" -TargetName "GG_Dev" -TargetType Group -PermissionLevel GpoDeny
```

### Tableau récapitulatif des forces


| Réglage             | Se pose sur...          | Contre quoi il gagne                                        |
| ------------------- | ----------------------- | ----------------------------------------------------------- |
| `Order 1`           | un lien (GPO ↔ OU)      | les autres GPOs de la même OU                               |
| `Enforced`          | un lien (GPO ↔ OU)      | tout ce qui est en dessous, **y compris Block inheritance** |
| `Block inheritance` | une OU                  | tout ce qui vient d'au-dessus (sauf Enforced)               |
| `GpoDeny`           | une GPO, pour un groupe | **contre absolument tout** (même Enforced)                  |


> 🧠 Hiérarchie finale à retenir : **GpoDeny &gt; Enforced &gt; Block inheritance &gt; LinkOrder**.

## 6. Filtrer : limiter à qui s'applique la GPO

```powershell
# Appliquer SEULEMENT à un groupe
Set-GPPermissions -Name "GPO_Fond_Ecran" -TargetName "GG_Compta" -TargetType Group -PermissionLevel GpoApply

# Retirer le filtre par défaut (tous les utilisateurs authentifiés)
Set-GPPermissions -Name "GPO_Fond_Ecran" -TargetName "Utilisateurs authentifiés" -TargetType Group -PermissionLevel None

# Déléguer la modification de la GPO à des admins
Set-GPPermissions -Name "GPO_Fond_Ecran" -TargetName "Admins du domaine" -TargetType Group -PermissionLevel GpoEdit

# Refus explicite (gagne contre tout)
Set-GPPermissions -Name "GPO_Fond_Ecran" -TargetName "GG_Stagiaires" -TargetType Group -PermissionLevel GpoDeny
```

> ⚠️ Par défaut, une GPO s'applique à **tous** les Utilisateurs authentifiés de l'OU liée. Le pattern : `GpoApply` au groupe cible **+** `None` aux Utilisateurs authentifiés.

## 7. Copier / sauvegarder / restaurer

```powershell
# Cloner une GPO existante (le pattern "GPO modèle")
Copy-GPO -SourceName "GPO_Modele" -TargetName "GPO_Compta"

# Sauvegarder
Backup-GPO -Name "GPO_Fond_Ecran" -Path "C:\BackupGPO"

# Restaurer
Restore-GPO -Name "GPO_Fond_Ecran" -Path "C:\BackupGPO"

# Importer dans un autre domaine (migration)
Backup-GPO -Name "GPO_Modele" -Path "C:\BackupGPO"
Import-GPO -TargetName "GPO_Compta" -Path "C:\BackupGPO" -BackupId "<guid-du-backup>"
```

## 8. Appliquer et tester

```powershell
# Forcer l'application immédiate (sans attendre le refresh ~90 min)
Invoke-GPUpdate -Computer "PC-Compta" -RandomDelayInMinutes 0

# Forcer seulement la moitié utilisateur
Invoke-GPUpdate -Computer "PC-Compta" -Target "User"

# Le rapport RsoP : ce que reçoit VRAIMENT un couple utilisateur/machine
Get-GPResultantSetOfPolicy -Computer "PC-Compta" -User "GreenTechSprint\j.nanas" `
    -ReportType Html -Path "C:\rapport.html"
```

> 💡 Le RsoP (`Get-GPResultantSetOfPolicy`) est **LE** réflexe diagnostic : il liste les GPOs gagnantes et perdantes, avec les valeurs finales.

---

## 9. Délier / supprimer

```powershell
# Délier une OU (la GPO existe toujours)
Remove-GPLink -Name "GPO_Fond_Ecran" -Target "OU=Utilisateurs,DC=GreenTechSprint,DC=fr"

# Supprimer la GPO elle-même
Remove-GPO -Name "GPO_Fond_Ecran" -Confirm:$false
```

## 10. 🧠 Mémo pièges d'examen

1. **3 concepts séparés** : la GPO (règlage), le lien (où), le filtrage (qui)
2. Moitié **Utilisateur** = à l'ouverture de session ; moitié **Ordinateur** = au démarrage (+ refresh 90 min)
3. **Ordre** : Site → Domaine → OU → sous-OU — le plus proche gagne ; `Order 1` = priorité max sur une même OU
4. **Enforced** prime sur tout en dessous ; **Block inheritance** coupe ce qui vient du dessus ; un **GpoDeny** gagne contre tout
5. Par défaut une GPO s'applique à tous les **Utilisateurs authentifiés** → filtrer = `GpoApply` au groupe + `None` aux authentifiés
6. `HKCU\` = réglage utilisateur · `HKLM\` = réglage ordinateur (dans `Set-GPRegistryValue`)
7. `Invoke-GPUpdate` = application immédiate (sinon attendre le refresh)
8. Diagnostic = `Get-GPResultantSetOfPolicy` (RsoP)
9. Réglages complexes → GPMC une fois, puis `Copy-GPO` / `Backup` + `Import-GPO` pour déployer
10. `Remove-GPLink` ≠ `Remove-GPO` : délier garde la GPO, supprimer l'efface
