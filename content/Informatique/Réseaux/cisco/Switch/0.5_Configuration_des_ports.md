# Configuration des ports d'un commutateur (Port Security)

## Les trois façons de sécuriser les adresses MAC

### Sécurisation statique

Les adresses MAC sont configurées **manuellement**. Elles sont stockées
dans la table d'adresses MAC **et** ajoutées à la configuration en cours.

```text
Switch> enable
Switch# configure terminal
Switch(config)# interface fa0/5
Switch(config-if)# switchport mode access
Switch(config-if)# switchport port-security
Switch(config-if)# switchport port-security mac-address [MAC]
Switch(config-if)# end
```

### Sécurisation dynamique

Les adresses MAC sont **apprises dynamiquement** (une seule par port
par défaut). Elles sont stockées dans la table d'adresses MAC uniquement
→ perdues au redémarrage du switch.

```text
Switch> enable
Switch# configure terminal
Switch(config)# interface fa0/5
Switch(config-if)# switchport mode access
Switch(config-if)# switchport port-security
   → limite automatique : 1 adresse MAC par port
Switch(config-if)# end
```

### Sécurisation rémanente (sticky)

Les adresses MAC sont **apprises dynamiquement mais converties en
statiques** : elles sont sauvegardées dans la running-config.

```text
Switch> enable
Switch# configure terminal
Switch(config)# interface fa0/5
Switch(config-if)# switchport mode access
Switch(config-if)# switchport port-security
Switch(config-if)# switchport port-security maximum [nb max d'adresses MAC]
Switch(config-if)# switchport port-security mac-address sticky
Switch(config-if)# end
```

## Vérification et diagnostic

### Port Security

```text
show port-security
   → résume la configuration de Port Security sur tous les ports

show port-security interface [interface]
   → configuration de sécurité d'un port spécifique (ex: fa0/5)

show port-security address
   → liste toutes les adresses MAC sécurisées sur le switch

show port-security address interface [interface]
   → liste les adresses MAC sécurisées d'un port spécifique
```

### Adresses MAC

```text
show mac address-table dynamic
   → affiche toutes les adresses MAC apprises dynamiquement

show mac address-table dynamic vlan [ID]
   → filtre les adresses MAC dynamiques pour un VLAN spécifique

show mac address-table static
   → affiche les adresses MAC configurées manuellement
```

### État des ports

```text
show interface status
   → état de tous les ports (up/down, err-disabled, etc.)

show interface [interface]
   → détails complets d'un port (trafic, erreurs, état)

show running-config interface [interface]
   → configuration active d'un port
```

### En cas de problème

```text
show logging   include security
   → affiche les logs liés à la sécurité (violations de Port Security)

clear port-security sticky [interface]
   → supprime les adresses MAC sticky sur un port
```
