# Affichage des informations système (mode privilégié)

```text
show version	→ affiche la version de l'IOS et les caractéristiques du routeur

show running-config	 → affiche la configuration en cours (RAM)

show ip interface brief	→ liste les interfaces avec leur état et leur adresse IP

show line	→ montre les configurations des différentes consoles CTY ou VTY
     (variante : show running-config   include line vty)

show port-security	→ montre la sécurisation des différents ports du commutateur
```
