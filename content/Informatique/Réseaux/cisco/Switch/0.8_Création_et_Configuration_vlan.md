# Guide : Création et Configuration de VLAN, VTP et Trunk

&nbsp;

## 📌 Création et Configuration de Base des VLAN

&nbsp;

### Création d’un VLAN

Pour créer un VLAN sur un switch Cisco, utilisez les commandes suivantes :

```cisco
Switch(config)# vlan 10
Switch(config-vlan)# name Comptabilité
Switch(config-vlan)# exit
```

&nbsp;

## 🌐 Affectation d’une IP à un VLAN

Pour permettre la gestion d’un VLAN via une adresse IP (ex: pour un routeur ou un switch Layer 3) :

```cisco
Routeur(config)# interface vlan 10
Routeur(config-if)# ip address 192.168.10.1 255.255.255.0
Routeur(config-if)# no shutdown
Routeur(config-if)# exit
```

&nbsp;

## 🔌 Affectation d’un Port à un VLAN

Pour associer un port physique à un VLAN en mode **accès** :

```cisco
Switch(config)# interface FastEthernet0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# no shutdown
Switch(config-if)# exit
```

## Vlan Trunk

```cisco
Switch(config)# interface fa0/11
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 5,10
```

## Vérification 

```cisco
Switch# show vlan brief            ← VLANs, noms, ports membres
Switch# show interfaces trunk      ← ports trunking + VLANs autorisés/actifs
Switch# show running-config        ← config complète
```
