1.0 # Fiche ROUTEUR — DHCP

## 1. Création / Configuration

```text
enable
conf t 
int fa0/0
ip address 172.16.5.2 255.255.255.0
no shutdown 
exit 

Router(config)# ip dhcp excluded-address 172.16.5.1 172.16.5.10
Router(config)# ip dhcp pool VOIC
Router(dhcp-config)# network 172.16.5.0 255.255.255.0
Router(dhcp-config)# default-router 172.16.5.1
Router(dhcp-config)# dns-server 1.1.1.1
```

| Commande | Rôle |
|---|---|
| `ip dhcp excluded-address <début> <fin>` | Réserve des IP hors distribution (gateway, serveurs). En mode config **globale**, AVANT le pool |
| `ip dhcp pool <nom>` | Crée un pool et entre dans sa configuration (`dhcp-config`) |
| `network <réseau> <masque>` | Plage distribuée par le pool |
| `default-router <ip>` | La gateway annoncée aux clients (pas forcément le routeur lui-même !) |
| `dns-server <ip>` | Serveur DNS annoncé aux clients |

> ⚠️ Toujours exclure les IP fixes (gateway .1, serveurs .2...) sinon le DHCP peut distribuer l'adresse de la gateway à un client → conflit IP → routage cassé (le piège du TP 😄).

## 2. Contrôle / Vérification

```text
Router# show ip dhcp binding        ← baux distribués (IP + MAC client)
Router# show ip dhcp pool           ← config du pool + statistiques
Router# show ip dhcp conflict       ← adresses marquées en conflit
Router# show running-config         ← pool + exclusion visibles dans la config
```

> ⚠️ Un bail reste dans la table même client débranché (pas d'expiration dans PT). Seul le **client** peut redemander une IP (reboot du téléphone, static→DHCP sur un PC : `ipconfig /release` puis `ipconfig /renew`).

## 3. Suppression / Réinitialisation

```text
Router# clear ip dhcp binding *              ← vide la table des baux (IOS réel)
Router# clear ip dhcp conflict *             ← vide la table des conflits (IOS réel)
Router# clear ip dhcp binding <ip>           ← supprime UN bail précis (IOS réel)
Router# reload                               ← méthode PT : reboot = table vidée
```

> ⚠️ Dans Packet Tracer, `clear ip dhcp binding` est souvent **absent ou refusé** (`% Invalid input`). Solution fiable : `copy running-config startup-config` puis `reload` (la config survit, la table des baux disparaît).

```text
Router(config)# no ip dhcp pool VOIC                  ← supprime le pool entier
Router(config)# no ip dhcp excluded-address 172.16.5.1 172.16.5.10   ← supprime l'exclusion
Router(dhcp-config)# no network 172.16.5.0 255.255.255.0             ← retire une option du pool
Router(dhcp-config)# no default-router 172.16.5.1
Router(dhcp-config)# no dns-server 1.1.1.1
```

> Pour modifier une option, inutile de supprimer le pool : retape la commande avec la nouvelle valeur (elle remplace l'ancienne). Le `no <option>` ne sert que pour la retirer complètement.
